### F2 — CONFIRMED (P2) · Contract drift: desktop section spacing 96px vs spec 112px
- brand-spec Layout contract: desktop 112px / mobile 72px.
- Rendered (all homepage sections): `py-18 md:py-20 lg:py-24` → 96px desktop padding; mobile 72px matches exactly.
- Either the spec is stale or the implementation drifted. Traceability marks GEO-01 "Rendered pass", so this slipped through a prior QA round.
- Suggested response: decide which number is canonical; update the other; record a change note.

### F3 — CONFIRMED off-token color + PLAUSIBLE neutral-run violation (P2)
- Metric suffixes in ByTheNumbers use `#0b7488` — teal-family but not a brand-spec token (accent is `#0e8fa8`). Likely a contrast-darkened derivative that was never written back into the spec.
- Storyboard assigns Outcomes "brand-supporting pale field / primary+secondary brand tones"; rendered band has zero token-exact CIS elements (bg is neutral paper-2, numerals ink).
- Sequence risk: Services' only CIS anchor is 3px active rails; Numbers and People are effectively neutral → reading of brand-spec "no more than two consecutive neutral light sections" is borderline-violated depending on whether 3px rails count ("tiny labels and divider lines alone do not establish brand presence").
- Suggested response: register the derived token in brand-spec (or use the approved accent), and give Numbers one meaningful brand element per the storyboard plan.
